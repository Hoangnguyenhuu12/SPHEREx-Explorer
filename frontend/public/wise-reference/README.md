# RW Aur AllWISE reference images

These previews were rendered from the team's local AllWISE W1/W2 FITS files at
`data/imports/full_harvest_fusion/data/harvest/rwaur/wise/` using
`scripts/render_wise_reference.py`. FITS headers identify WISE/IPAC and coadd
`0765p302_ac51`, with contributing observations from 2010-03-03 to 2010-09-12 UTC.
The source W1 SHA-256 is `fe8b73c83140a1949ecaf0e474a07799aa1327cf81964cc05078c73ee35551c7`;
W2 is `3f24375896f7a603e0056a50329460b53df5760e1b58e75a5265120348774a05`.
The target's J2000 catalog position falls in both images; this does not establish a detection.
The previews are independently percentile and asinh stretched, and are not photometric products.
